# 元素周期律 · 第一课时 互动课堂

一套面向高中化学「元素周期律」第一课时的离线互动课件。以"镁铝合金"为情境线索，把原子结构、原子半径、离子半径、常见化合价拆成四个可独立操作的小任务，学生在平板或电脑上翻卡、拖拽、观察图表，自主归纳规律。

纯静态页面，无框架、无构建、无外部依赖，双击即可运行，适合课堂投屏与分组探究。内置日间 / 夜间两套配色，按一次按钮即可切换，并记住上次的选择。

## 四个任务

| 任务 | 主题 | 核心操作 | 数据口径 |
| --- | --- | --- | --- |
| 任务一 | 构造原子结构示意图 | 调节质子数与电子数，判断中性原子与电子层排布，把正确的结构示意图点亮到周期表 | 1—36 号，主族与 0 族共 26 个可点亮元素 |
| 任务二 | 原子半径卡片探究 | 在悬浮卡片池中翻面读半径，拖回周期表对应格子，寻找与铝原子半径相近的原子 | 共价半径 / pm，Cordero 等，2008 |
| 任务三 | 离子半径与核外电子排布 | 对比 Mg²⁺、Al³⁺ 等 10 电子离子的半径，并一键叠加原子半径看得失电子前后的变化 | 离子半径 / pm，Shannon 1976 |
| 任务四 | 常见化合价卡片探究 | 翻面读出常见价态，拖回周期表，观察最高正价、最低负价在散点图中的分布 | 1—20 号元素常见价态（含负价） |

主页面四个任务默认背面朝上，供小组盲选后翻开；每个任务页都提供进度、统计、计时与一键展开的记录面板。

## 快速开始

方式一：直接双击 `index.html`，用 Chrome / Edge 打开即可（推荐全屏，F11）。

方式二：起一个本地静态服务器：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000/`。

> 页面按 1920×1080 设计，使用等比缩放适配任意窗口，投屏与平板横屏都有较好的可读性。若修改过代码后仍是旧样式，按一次 `Ctrl+F5` 强制刷新。

## 交互与教学细节

- **周期表**：1—36 号元素，18 列 × 4 行。未归位/未点亮的格子只显示原子序数，学生需要根据卡片上的符号自行判断位置；归位或点亮后才显示符号或结构示意图。
- **结构示意图**：按教材画法，原子核在左侧，电子层用约 90° 的同心圆弧表示，电子数嵌在弧线正右方的缺口里。
- **卡片池**：卡片顺序每次加载随机打乱，围绕各自位置缓慢漂浮，轻点翻面、按住可拖拽到周期表；放错格子标红但不打断操作，可拖出重放。
- **翻面与放大**：卡片翻面是与主页面任务卡一致的 3D 翻转动画。每张卡片**只在第一次翻到背面时自动放大**——飞到屏幕中央、背景虚化，停留约 2.6 秒再缩回原位，方便后排学生读数据；之后再想放大，点卡片背面右下角的**放大镜按钮**即可（只放大，不翻面、不计入翻面次数）。点击任意位置可提前收起。
- **散点图**：横坐标为原子序数，坐标轴范围固定不缩放，避免不同班级读数不一致。散点**只绘制已正确归位到周期表的卡片**——翻面只负责读数，必须把卡片放对格子后数据才会出现在图上，让学生沿着“位置 → 结构 → 性质”的顺序推进。
- **任务三对照**：点「叠加原子半径」可把已正确归位离子对应元素的原子半径以异色空心点叠加，直观看出得失电子后的半径变化。
- **任务四分色**：最高正价、最低负价、其他常见价态分别用深青、橙、浅青标注，散点与卡片背面保持一致。
- **计算器**：任务二提供半径差值计算器，收在右下角浮层中，按需展开，不占用主视觉。
- **三维模型**：任务一的原子模型用 Canvas 实时绘制，电子沿分层轨道运动，随质子数、电子数即时更新。

## 界面与阅读

- **字号**：正文按投屏阅读放大到 17—19px，论文式标题、目标句与关键数值保持加粗，其余正文保持常规字重，避免整页都变粗反而看不清。
- **配色**：日间为米白纸感 + 墨绿文字；夜间自动切到深墨绿底 + 亮薄荷文字，卡片、周期表、散点图、原子结构示意图、记录浮层一起换色，图表颜色通过 CSS 变量读取，切换时自动重绘。
- **切换方式**：顶栏右侧「夜间模式 / 日间模式」按钮，选择会记在本机，下次打开沿用；首次进入默认日间。
- **无障碍与对比度**：夜间模式正文、标签、图例的对比度均在 4.5:1 以上，图形元素不低于 3:1。

## 记录与隐私

所有翻面次数、归位状态、停留时间、点亮进度都保存在浏览器 `localStorage` 中，刷新不丢失，不上传任何服务器。日间 / 夜间模式的选择同样只存在本机。点击页面上的「清空记录 / 重置」可恢复初始状态。

## 浏览器支持

Chrome / Edge / Safari / Firefox 近两年版本；平板建议横屏使用。三维模型依赖 Canvas 2D，无需 WebGL。

## 数据来源

- 共价半径：Cordero, B. et al. *Dalton Trans.*, 2008, 2832–2838.
- 离子半径：Shannon, R. D. *Acta Cryst. A*, 1976, 32, 751–767（取教材常见的简单离子数据口径）。
- 常见价态：高中化学教材常见价态范围（含负价），仅取 1—20 号元素。
- 电子层排布：按 2、8、18… 规律，最外层不超过 8。

数据为课堂教学统一口径，过渡金属不进入任务四卡片池，详见各任务页的「数据口径」说明。
